# Managing the L2 Angkor website

## The admin page

Open **https://l2angkor.sanity.studio** (or **yoursite.com/admin**, which goes to the same place)
and log in with the Google account that owns the project (ann.heak123@gmail.com).

The admin has two sections on the left:

- **Rooms**: one entry per room type.
- **Website settings**: home page photos, gallery, contact details, lease rules and payment.

Changes go live when you press **Publish** (bottom right). Until then they are saved as a draft that
visitors can't see.

> **Sample content:** the 4 rooms, their prices and descriptions, and *all photos* are samples
> (the photos were generated by AI). Replace them with your real rooms and photos before launch.

---

## Rooms

Click **Rooms**, then a room to edit it, or the **+** / pencil icon to add a new one. Each room has tabs:

**Basics**
- **Room name**: English, Khmer and Chinese boxes. If Khmer or Chinese is empty, English is shown.
- **Web address**: click **Generate** after typing the English name.
- **Show on website**: turn off to hide the room without deleting it.
- **Show on home page**: up to three rooms are shown on the home page.
- **Monthly price from (USD)**: a number, e.g. `350`.
- **Availability**: *Available now*, *Available from a date* (then pick the date), or *Rented*.
- **Size**, **Bedrooms** (0 = studio), **Bathrooms**, **Maximum people**.
- **Display order**: lower numbers appear first.

**Photos**: drag photos in (or click *Upload*). Drag to reorder; the **first photo** is the main one.
Click a photo to set the focus point, so the important part stays visible when it's cropped.

**Furniture**: tick everything that is in the room. Anything not in the list goes under
*Other items not in the list*.

**Services**: tick the services included in the rent (Wi-Fi, cleaning, parking…), plus any others.

**Description**: a short one-line summary for the room card, and the full description
(leave an empty line between paragraphs).

The **Rooms page** on the website builds its filters from what you tick here, so customers can search
by price, availability, furniture and services.

## Website settings

- **Photos**: the main home page photo (wide, at least 2000 px), the "Our family" photo, an optional
  logo, and the gallery photos with captions.
- **Contact**: phone, Telegram username, WhatsApp number (digits with country code, e.g.
  `85512345678`), Facebook link, WeChat ID and QR code, email and address. Leave a field empty to
  hide that button.
  - **Map**: in Google Maps, find the building → **Share** → **Embed a map** → copy only the link
    inside `src="…"` into *Google Maps embed link*. Then **Share** → **Copy link** into *Google Maps link*.
- **Lease rules**: minimum lease, deposit, pets, electricity and water prices, and the services for
  all tenants shown on the home page.
- **Payment**: turn on *Show payment section* and add your KHQR code and bank details when you're ready.

## Inviting family members

Go to **https://www.sanity.io/manage** → project **L2 Angkor** → **Members** → **Invite**. Give them
the *Editor* role.

## For developers

```bash
npm install && npm run dev              # website on http://localhost:3000
cd studio && npm install && npm run dev # admin on http://localhost:3333
```

Deploy the admin after changing its schema (`studio/schemaTypes`): `cd studio && npx sanity deploy`
(requires `npx sanity login` with the project owner's account).

### Publish the website on Vercel

1. Push this repository to GitHub, then on <https://vercel.com> choose **Add New → Project** and import it.
2. Add the environment variables from `.env.example`.
3. Add the live address to Sanity's allowed origins (<https://www.sanity.io/manage> → API → CORS
   origins) if it isn't a `*.vercel.app` address, which is already allowed.

### Instant updates after publishing

Pages refresh automatically while visitors are on them. To make sure every visitor sees a change
immediately, add a webhook once the site is live:

1. <https://www.sanity.io/manage> → L2 Angkor → **API** → **Webhooks** → **Create webhook**.
2. URL: `https://<your-site>/api/revalidate`, Dataset: `production`, Trigger on: Create, Update, Delete,
   Filter: `_type in ["room", "siteSettings"]`, HTTP method: POST.
3. Secret: a long random text. Put the same text in Vercel as `SANITY_REVALIDATE_SECRET`.

### Enquiry form

Until email or Telegram is set up, the form runs in test mode: visitors see "Thank you", but the
message only appears in the server log.

- **Email (Resend, free tier)**: sign up at <https://resend.com>, create an API key, and set
  `RESEND_API_KEY` and `INQUIRY_TO_EMAIL`.
- **Telegram**: message **@BotFather** → `/newbot` → copy the token into `TELEGRAM_BOT_TOKEN`. Send
  your bot a message, then get your chat ID from **@userinfobot** and set `TELEGRAM_CHAT_ID`.

### Colours and fonts

Colours are at the top of `src/app/globals.css`; fonts are in `src/lib/fonts.ts`.
